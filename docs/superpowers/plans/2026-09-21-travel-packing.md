# 旅行打包实现记录

**目标：** 输入目的地与时长后，由 Jev 选择旅行物品，以吸附动画组成可操作的打包清单。

**结构：** 共享物品目录、Jev 后端、原生网页、Matter.js 物理模块，以及 Cloudflare Worker 线上版本。

## 项目范围

- 默认首页是旅行打包 app，兼容 `/travel/` 路径。
- 接口为 `GET /api/health` 和 `POST /api/pack`。
- 服务端保管密钥，失败时显示错误，不能用模拟结果冒充 Jev 推荐。
- 月份默认当前月份，页面说明没有接入实时天气。

## 已实现

- [x] 后端：校验旅行描述，调用 Jev，校验全部概率，筛选已知物品并限制为 24 件。
- [x] 页面：输入停顿或回车查询、三个示例、清空、状态提示、清单勾选与复制。
- [x] 请求管理：中文输入法、连续改写、请求取消、响应乱序、重复查询与 BFCache 恢复。
- [x] 物理动画：堆积、抓取位置拖拽、保留惯性、弧线上浮、减速归位与回落碰撞。
- [x] 连续切换：修改行程保留悬浮物品，成功后只调整变化项；失败保留当前清单。
- [x] 适配：桌面、手机、键盘、窗口缩放与减少动态效果。
- [x] 线上版本：Worker 入口、静态资源白名单、服务端 secret、构建与验证脚本。
- [x] 验证：旅行 API、页面交互、真实 Matter 物理模拟、构建资源与凭证隔离测试。

## 验证重点

- 目的地和时长不完整、空结果、接口失败都能恢复。
- 旧请求不能覆盖新的行程或用户手动调整。
- 默认首页和 `/travel/` 展示同一旅行 app。
- 多件物品不能卡在休眠的物品堆里，释放后应落回边界内。
- 静态文件和错误响应不能泄露凭证。
