# 带什么 · 旅行打包

用户希望复刻所提供视频的语义吸附交互，改为输入旅行目的地和时长，相关旅行 emoji 自动浮起。成功标准是一个本机可直接打开、真实调用 Jev、桌面和手机可操作的页面。

界面采用暖白背景、橙色重点、深色中文标题。主操作只有自然语言输入框；示例是快捷填入真实查询。页面下方是旅行物品的物理堆积，上方为模型选中的物品，物品可拖动。清空后落回底部。提供可勾选的侧边打包清单以及复制清单。

2026-09-21 用户提供新参考图并要求更简洁：视觉方案更新为浅灰底、居中的白色输入框、三个示例 chips、上方选中 emoji 与底部物品堆。移除品牌、大标题、介绍和页脚；物品名只在悬停或键盘聚焦时显示。清单、帮助与抖动入口收至右上角。加载、错误、空结果状态仍可见，成功和待输入时隐藏额外文案。月份假设移到清单内说明。

沿用 Node 本机服务器和现有 key；新增 /travel 页面及 /api/pack，不覆盖原有聊天页面。前端使用原生 HTML/CSS/ES modules 和 Matter.js 0.20。固定物品库为双方共享模块。后端批量询问 Jev 每件物品是否适合旅行，并校验所有答案为概率后返回已知物品 ID。没有目的地和时长时提示补充；未写月份时明确按当前月份考虑，月份推断不表示实时天气。

输入停顿 850ms 后请求，Enter 立即请求。处理中文输入法、取消旧请求与过期响应，重复成功请求可在本页缓存。加载、无匹配、失败和未配置 key 均有明确状态，失败不伪造模型结果。用户可手动调整清单与标记已装好；修改为新旅程后重新开始打包进度。
