# 带什么 · 旅行打包

这是一个旅行打包 app。用户输入目的地和旅行时长，Jev 选择适合携带的物品，相关 emoji 从底部物品堆自动浮起。成功标准是本地和线上均可使用，真实调用 Jev，支持桌面、手机和键盘操作。

界面参考用户提供的视频与截图：浅灰背景、居中的白色输入框、三个示例 chips、悬浮 emoji 和底部物品堆。物品名称在悬停或聚焦时显示；清单、帮助与抖动入口位于右上角。加载和错误提供明确反馈。

本地 Node 服务在 `/` 和 `/travel/` 提供旅行页面，接口仅包含 `/api/health` 和 `/api/pack`。线上版本使用 Cloudflare Worker，保持相同的页面和 API 行为。前端使用原生 HTML/CSS/ES modules 与 Matter.js 0.20。

物品目录由前后端共享。服务端用 Jev 的结构化概率判断 56 件物品，校验完整结果后返回最多 24 个已知物品 ID。目的地或时长不完整时提示补充。未写月份时按当前月份考虑，不声称获取了实时天气。

输入停顿 850ms 后请求，Enter 立即请求。处理中文输入法、请求取消、响应乱序和重复查询缓存。修改非空行程时保留悬浮物品，成功后调整变化项；失败保留当前清单；清空输入立即释放物品。新行程重置打包进度，同一行程重复提交保留手动调整与勾选。

物品采用连续弹簧吸引力，保留惯性与旋转；回落时与底部物品碰撞。拖动按实际抓取位置施力。支持窗口缩放和系统减少动态效果设置。

密钥只在服务端读取。静态资源采用白名单，不暴露配置、源码或目录浏览。测试覆盖行程校验、模型结果校验、接口隔离、清单交互、物理行为和线上构建。
